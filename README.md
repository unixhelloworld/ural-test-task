# Поиск запчастей

React + Redux Toolkit + Bootstrap, сборка на Vite. API: [Favorit Parts — Проценка](https://lk.favorit-parts.ru/static/wsprice.pdf).

## Запуск

```bash
cp .env.example .env   # указать свой ключ в VITE_API_KEY
npm install
npm run dev
```

В `.env.example` лежит тестовый ключ из документации.

## Как работает

1. Ввод артикула (от 3 символов, с задержкой 500 мс) — запрос `?number=...`, из ответа берётся список уникальных производителей.
2. Клик по производителю — запрос `?number=...&brand=...&analogues=on`. В таблице сама деталь и её аналоги, по строке на каждый склад: цена и остаток берутся из склада, как требует документация.

Запросы идут через dev-прокси Vite (`/api` → `api.favorit-parts.ru/hs/hsprice`), так как API работает по http.

Обрабатываются: загрузка, сетевые ошибки, ошибки API (`{ error }`), пустой ответ (API возвращает массив с одной пустой записью). Устаревшие запросы отменяются при новом вводе.

## Структура

```
src/
  api/favorit.js         запросы и нормализация ответа
  store/searchSlice.js   состояние поиска и thunk'и
  components/            форма, список брендов, таблица, лоадер, ошибка
```
